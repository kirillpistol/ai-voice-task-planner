# Экраны PISTOL GENESIS

Каталог макетов интерфейса на русском и английском языках, включая светлую и тёмную темы.

- [Русские экраны — RU](ru/README.md)
- [Английские экраны — EN](ru/README.md#английская-версия-uk-english)
- [Манифест изображений](manifest.json)

## Каталоги

| Путь | Содержимое |
|---|---|
| `ru/auth/`, `en/auth/` | Вход, регистрация, восстановление пароля |
| `ru/calendar/`, `en/calendar/` | Календарь и выбор даты |
| `ru/tasks/`, `en/tasks/` | Карточки и редактирование задач |
| `ru/profile/`, `en/profile/` | Профиль и настройки |
| `ru/voice/`, `en/voice/` | Голосовой ввод и подтверждение |
| `original/` | Исходные визуальные референсы |

Манифест содержит пути, темы, языки, размеры и контрольные суммы изображений.
