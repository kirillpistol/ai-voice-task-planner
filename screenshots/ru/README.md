# Русские экраны PISTOL GENESIS

**28 входных файлов, 27 уникальных макетов**, полученные тремя партиями. Русский комплект загружен в полном объёме полученных изображений; тёмное подтверждение успешного добавления задачи пока не предоставлено. Английская версия ожидается отдельно. Это макеты интерфейса, не подтверждение реализации функций в приложении.

PNG сохранены без изменения байтов, пикселей и размеров. 23 изображения имеют размер 864 × 1821 px, три тёмных экрана (недельный календарь, запись, проверка задачи) — 863 × 1822 px, тёмное меню настроек — 863 × 1823 px. Суффикс «(1)» в имени подтверждения удаления обозначает светлый вариант, а не дубликат.
