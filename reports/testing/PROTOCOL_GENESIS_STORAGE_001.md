# GENESIS — Протокол тестирования хранилища

**Протокол:** GENESIS-STORAGE-001  
**Дата:** 27.10.2026  
**Статус:** два локальных теста выполнены пользователем; 1 ТБ — только прогноз  
**Ветка:** `reports/storage-benchmark-1tb`

## 1. Цель
Оценить скорость последовательной записи синтетических данных на локальный накопитель и предварительное время записи 1 ТБ. Тест **не измеряет** скорость получения информации из банковских приложений или производительность API.

## 2. Методика
Скрипт `reports/testing/storage_benchmark.py` создаёт временный файл с синтетическими данными, последовательно записывает заданный объём, вызывает `flush()` и `os.fsync()`, измеряет время `time.perf_counter()`, удаляет временный файл. Между прогонами результаты могут зависеть от файлового кеша, состояния накопителя и нагрузки ОС.

Формулы:
- `throughput_mib_s = written_mib / elapsed_seconds`
- `time_for_1tb_hours = 1_000_000_000_000 / (throughput_mib_s * 1_048_576 * 3600)`

## 4. Интерпретация
Результаты показывают локальную последовательную запись примерно 300 МиБ/с в коротких тестах. Это **не** означает, что реальный поток записей в базу данных будет иметь такую же скорость: индексы, транзакции, сжатие, репликация, сетевые задержки и резервное копирование могут существенно изменить итог.

## 5. Повторение на Windows
Из корня скачанной тестовой ветки:

```powershell
python .\reports\testing\storage_benchmark.py --mib 256 --iterations 3 --output storage_benchmark_256mb.json
python .\reports\testing\storage_benchmark.py --mib 2048 --iterations 3 --output storage_benchmark_2gb.json
```

Для следующего этапа, **только если свободно минимум 15 ГиБ**:

```powershell
python .\reports\testing\storage_benchmark.py --mib 10240 --iterations 1 --output storage_benchmark_10gb.json
```

Выходные JSON-файлы создаются локально и не отправляются в GitHub автоматически. Скрипт не обращается к банковским системам и не обрабатывает личные данные.

## 6. Критерии следующего этапа
1. Зафиксировать модель накопителя, свободное место и тип файловой системы.
2. Сравнить результаты 256 МиБ, 2 ГиБ и 10 ГиБ.
3. Выполнить отдельный тест **синтетической базы данных** с индексами и транзакциями.
4. Уточнить физическую ёмкость для 1 ТБ логических данных с учётом индексов и резервирования.
