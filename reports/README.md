# GENESIS — Отчёты по тестированию

**Ветка:** `reports/storage-benchmark-1tb`  
**Статус:** локальные тесты 256 МиБ и 2 ГиБ завершены; 10 ГиБ ожидает запуска.

## Результаты

| Показатель | 256 МиБ × 3 | 2 ГиБ × 3 |
|---|---:|---:|
| Медиана, МиБ/с | 323.47 | **303.22** |
| Минимум, МиБ/с | 246.16 | 278.95 |
| Максимум, МиБ/с | 363.78 | 328.78 |
| Расчёт записи 1 ТБ | ~49 мин | **~52 мин** |

> Важно: оценка 1 ТБ — экстраполяция, не результат фактической записи 1 ТБ. Измерения относятся к локальной записи синтетических файлов, а не к сбору данных из внешних сервисов.

## Запуск

```powershell
python .\reports\testing\storage_benchmark.py --mib 2048 --iterations 3
```

Результат записывается в `storage_benchmark_result.json`. После нового теста его значения следует добавить в протокол. Код теста не изменяет данные приложения GENESIS.
