Предварительный просмотр

Нажимая «Подготовить правило», вы отправляете комментарий, выбранную сферу и категорию на сервер. Сервер формирует текст предложения и контекст из ранее подтверждённых правил. Предварительный просмотр не сохраняет новый комментарий в базе памяти.

Подтверждение и согласие

После согласия на хранение и нажатия «Подтвердить правило» текст правила, его категория, сфера и время добавления сохраняются в серверной SQL-базе и связываются с вашим аккаунтом. Сервер нормализует пробелы; повторная отправка одинакового правила не создаёт копию. На сферу предусмотрено до 50 правил длиной до 2000 символов каждое.

Назначение и ограничения

Подтверждённые правила включаются в контекст следующих запросов того же аккаунта и сферы. Система не проверяет истинность правила: это указание пользователя. Функция готовит контекст, но не запускает алгоритмы трёх уровней GENESIS, не обучает параметры модели и не отправляет текст внешним ИИ-провайдерам. Это согласие не разрешает обучение общей модели на ваших данных.

Доступ и удаление

Пользовательский API требует авторизации и ограничивает доступ аккаунтом и сферой. Работа серверной инфраструктуры требует технического доступа администратора. Кнопка «Забыть правило» удаляет его из рабочей базы; оно перестаёт входить в новые контексты. Удаление не меняет календарь и не стирает ранее показанные результаты или ранее созданные резервные копии. Правила сохраняются до удаления пользователем; автоматическая очистка копий задач не распространяется на память правил.

Personal rule memory — English

Preview sends your comment, sector and category to the server to prepare a proposal using previously confirmed rules. It does not save the new comment in the memory database.

After storage consent and confirmation, the rule text, category, sector and creation time are stored in SQL under your account. Whitespace is normalized; identical retries do not create copies. Each sector supports up to 50 rules of up to 2000 characters.

Confirmed rules enter the context of subsequent requests for the same account and sector. They are user instructions, not verified facts. This feature prepares context; it does not execute the three-level pipeline, train model parameters or send text to external AI providers. Consent does not authorize general model training.

Authenticated user API access is account- and sector-scoped; infrastructure administration requires technical access. Forgetting a rule removes it from the live database and future contexts, while calendar data, earlier displayed results and existing backups remain unaffected. Rules remain until user deletion; calendar-copy cleanup does not erase rule memory.
