# GENESIS · Сканирование в комментариях (Android MVP)

Раздел GENESIS → выбор сектора → Комментарий → «Сканировать документ · Камера / Галерея».

## Реализовано в Android
- Отдельный экран-подтверждение с CameraX PreviewView, запросом Android CAMERA по необходимости.
- Системный выбор фотографий через GetContent; доступ ко всей галерее не запрашивается.
- Анимированная горизонтальная голубая линия поверх изображения камеры.
- **Тестовый автоснимок после 2,5 секунды работы Preview**. В текущей реализации это таймер стабилизации, **не детектор границ документа и не достоверная проверка фокуса**.
- On-device OCR ML Kit, просмотр и исправление текста, «✓ Добавить информацию».
- Подтверждённый текст помещается только в поле комментария выбранного сектора. Для отправки в GENESIS применяется уже существующая процедура Preview → Consent → Confirm. Нет автоматической передачи фотографии, хранения изображения или обучения модели.

## Безопасность
Для медицинских документов не использовать личные данные при тестировании. Оригиналы не отправляются в L2: настоящее персональное хранение, документное индексирование и RAG требуют отдельного контракта L2, авторизации пользователя, прав на источники и сквозного теста. Сканировать страницы книг следует только при наличии прав на выбранное использование.

## Проверить на физическом Android
1. Первый запуск: запрос CAMERA → показать превью; отказ → выбор через галерею.
2. Линия движется сверху вниз, фото снимается после задержки, текст появляется для редактирования.
3. Галерея работает без предоставления широкого доступа к фотографиям.
4. Кнопка «Добавить информацию» помещает OCR-текст в комментарий; **не создаёт правило GENESIS автоматически**.
5. Существующая процедура подтверждения комментария продолжает работать.
6. При отсутствии текста показывается ошибка и возможность переснять.
7. Проверить долгие строки, кириллицу (базовая модель ML Kit Latin лучше подходит для латиницы), поворот устройства, повторный вход, низкую освещённость.

## Далее
